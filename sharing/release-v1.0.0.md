Compatibility Playbooks v1.0.0 — Initial release

## GitHub release description

Compatibility Playbooks is a tool-neutral, Markdown-first set of AI workflows for enterprise engineering reviews.

This initial release includes workflows for:

- API compatibility reviews
- Event and message compatibility reviews
- Database and migration compatibility reviews
- Release readiness reviews
- Evidence-driven root cause analysis

Each playbook provides required inputs, a copy-ready prompt, a structured output format, and a fictional worked example. The workflows emphasize cited evidence, explicit assumptions and unknowns, mixed-version and rollout analysis, and concrete validation steps.

These playbooks are decision support. They do not replace deterministic contract or schema checks, tests, production knowledge, or human approval.

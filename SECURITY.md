# Security Policy

## Scope

This repository contains Markdown documentation and AI workflow prompts. It does not execute code or process repository data by itself.

## Reporting a security concern

Do not report vulnerabilities by posting secrets, exploit details, or sensitive incident data in a public issue. Use GitHub's **Report a vulnerability** feature for this repository when available, or contact the repository owner through the contact method listed on their GitHub profile. Include only the information needed to understand and reproduce the concern safely.

## Sensitive information

Never submit credentials, tokens, customer data, private logs, proprietary source, or confidential incident records in issues, pull requests, or examples. Sanitize and fictionalize examples before sharing. When using an AI assistant, follow your organization's data-handling rules; repository guidance does not override them.

## Supported versions

Security-related reports are addressed against the current default branch. The project does not currently publish a support window for older revisions.
